# NPP Australia (AP+)

> NPP Australia operates the New Payments Platform (NPP), Australia's national real-time, data-rich, account-to-account payments rail that settles 24/7/365 across 100+ connected banks, credit unions, fintechs and government agencies. Since 2021 it has been a wholly owned subsidiary of Australian Payments Plus (AP+). NPP Australia does not sell a consumable public API itself: it publishes the ISO 20022-aligned NPP API Framework that governs how NPP Participants build NPP APIs, and AP+ runs a registration-gated developer portal plus a SWIFT-hosted sandbox. The consumable APIs are offered by NPP Participants (banks and fintechs), and via AP+ the BPAY APIs.

## Overlay services and frameworks

- [NPP API Framework](https://www.auspayplus.com.au/solutions/npp-for-developers): ISO 20022-aligned framework (v5.0) defining the mandatory technical approach and data attributes for APIs built on the New Payments Platform. Published as a versioned specification, not a self-serve REST API.
- [PayTo](https://www.auspayplus.com.au/solutions/payto): Real-time digital mandated-debit overlay service; lets businesses initiate real-time debits under a pre-authorised agreement with consumer visibility and control.
- [PayID](https://www.auspayplus.com.au/solutions/payid): Addressing service mapping a mobile number, email, ABN or organisation ID to a bank account instead of a BSB and account number.

## BPAY APIs (AP+ developer portal, registration-gated)

- [Validate BPAY Payment API](https://www.developers.auspayplus.com.au/apis/bpay/validate-bpay-payment-api): Validate a set of BPAY payments to generate a BPAY batch file in the format specified by a financial institution.
- [Submit BPAY Payment API](https://www.developers.auspayplus.com.au/apis/bpay/submit-bpay-payment-api): Submit BPAY payments for processing and settlement.
- [Generate BPAY Batch File API](https://www.developers.auspayplus.com.au/apis/bpay/generate-bpay-batch-file-api): Generate a BPAY batch file in the format specified by a Batch Payer Institution.
- [Generate BPAY CRN API](https://www.developers.auspayplus.com.au/apis/bpay/generate-bpay-crn-api): Generate CRNs and intelligent CRNs (iCRNs) in accordance with Check Digit rules nominated against a Biller Code.
- [Manage BPAY Biller API](https://www.developers.auspayplus.com.au/apis/bpay/manage-bpay-biller-api): Request and delete pending changes for a specific BPAY Biller.
- [Retrieve BPAY Biller Details API](https://www.developers.auspayplus.com.au/apis/bpay/retrieve-bpay-biller-details-api): Retrieve details associated with a specified BPAY Biller, including Check Digit rules.
- [Manage BPAY Investigation API](https://www.developers.auspayplus.com.au/apis/bpay/manage-bpay-investigation-api): Create, retrieve and manage BPAY Payment Investigations.
